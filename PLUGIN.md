# Point Numbering

The **Number points** ribbon tool in **xfTools** uses the theme-aware `1,2…` glyph and starts an interactive placement command.

## Use

Run `PNUM` or select **xfTools → Number points**. On Windows and macOS, a compact settings window opens before placement. Set the start number, increment, prefix, text height, upper-right offset, and text style, then select **Start**. Linux keeps inline configuration.

- Click a vertex or empty location to add the next label.
- Press Enter or Esc to stop.
- The next value and settings remain available until OpenCADStudio is closed.
